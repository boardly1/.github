## What This Organization Is For

Boardly is the shared GitHub space for the Boardly project. It is prepared for future development work, project planning, team access, reviews, and repository ownership when the main codebase is ready to move here.

The current source repository is still hosted at [Timurc390/Boardly](https://github.com/Timurc390/Boardly). This organization is ready to receive it later without creating a conflicting `boardly1/Boardly` repository now.

## Repositories

| Repository | Purpose |
| --- | --- |
| [`Timurc390/Boardly`](https://github.com/Timurc390/Boardly) | Current main project repository. |
| [`boardly1/planning`](https://github.com/boardly1/planning) | Roadmap, ideas, issues, discussions, and coordination. |
| [`boardly1/.github`](https://github.com/boardly1/.github) | Organization profile and default community files. |

## How Work Should Flow

1. Track ideas, bugs, and roadmap items in [`boardly1/planning`](https://github.com/boardly1/planning).
2. Keep implementation changes in focused branches and pull requests.
3. Use reviews before merging into protected default branches.
4. Move the main repository into this organization when the current owner is ready to transfer it.

## Team Structure

| Team | Role |
| --- | --- |
| Maintainers | Repository administration, releases, and project direction. |
| Developers | Feature work, implementation, and maintenance. |
| Reviewers | Triage, review, and quality checks. |

## Current Setup

- Organization profile is configured.
