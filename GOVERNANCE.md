# Governance

Boardly uses a simple maintainer-led model.

## Maintainers

Maintainers are responsible for repository settings, releases, access control, and final merge decisions.

## Contributors

Contributors can propose issues, discussions, and pull requests. Work should be scoped clearly and reviewed before merge.
