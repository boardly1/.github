# Contributing

Thanks for helping with Boardly.

## Workflow

1. Open an issue for bugs, ideas, or larger changes.
2. Create a focused branch for the work.
3. Keep pull requests small enough to review clearly.
4. Add screenshots or notes when the change affects the UI or user flow.
5. Request review from a maintainer or reviewer before merging.

## Pull requests

A good pull request should include:

- what changed
- why the change was needed
- how it was tested
- any follow-up work that remains
