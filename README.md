# Boardly Organization Defaults

This repository powers the public Boardly organization profile and shared community defaults.

## Contents

- `profile/README.md`: public organization profile
- `CONTRIBUTING.md`: default contribution guide
- `SECURITY.md`: default security policy
- `SUPPORT.md`: default support policy
- `CODE_OF_CONDUCT.md`: community behavior expectations
- `PULL_REQUEST_TEMPLATE.md`: default pull request template
- `ISSUE_TEMPLATE/`: shared issue forms
- `DISCUSSION_TEMPLATE/`: shared discussion forms

Changes to this repository affect how future Boardly repositories look and how contributors open issues and pull requests.
